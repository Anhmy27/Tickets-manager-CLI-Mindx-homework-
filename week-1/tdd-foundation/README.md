## AI workflows đã áp dụng (Week 1)

Theo yêu cầu tuần 1, research cần chứng minh đã dùng 3 workflow:

1. **Layered Questioning** — Nghiên cứu → Tóm tắt → Ví dụ → Kiểm chứng
2. **Solution Exploration** — Khám phá lựa chọn → So sánh ưu/nhược → Chọn theo ngữ cảnh
3. **Iterative Refinement** — Xem xét → Tinh chỉnh → Phản hồi → Kiểm chứng

Chi tiết workflow gắn với từng phần research nằm trong từng file và link chat AI ở cuối mỗi file.
